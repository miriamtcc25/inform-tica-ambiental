# 🌍 Informática y medioambiente

## Protección medioambiental en el ámbito de la informática

Este proyecto colaborativo trata sobre el impacto medioambiental de la informática, los residuos electrónicos y las medidas que podemos aplicar para conseguir una tecnología más sostenible.

## 📑 Índice

- [Conclusión](sostenibilidad-informatica.md#9-conclusión)

## 🎯 Objetivos

- Conocer el impacto ambiental de la informática.
- Identificar los residuos electrónicos.
- Comprender la obsolescencia programada.
- Conocer la informática ecológica o Green IT.
- Proponer medidas para conseguir una informática más sostenible.
